# Documentation index

Start with the short, topic-specific document; do not read every Markdown file.

| If the task is about… | Read… |
|---|---|
| Current work/status | [tasks.md](./tasks.md) |
| Why an old request or implementation decision exists | [task-history.md](./task-history.md), then only the relevant numbered entry |
| Product priorities | [../roadmap.md](../roadmap.md) |
| Open or previously completed product backlog | [todos.md](./todos.md), when changing provider keys or API testing |
| Codespaces or local Supabase | [startup](./codespace.md#local-supabase-startup); [network diagnosis](./codespace.md#diagnose-before-retrying); [minimal Compose stack](./codespace.md#compose-local-app-and-supabase-compatible-services) |
| Database migration checks | [disposable migration checks](./codespace.md#disposable-migration-checks) |
| Commands, HTTP smoke tests, or browser E2E | [project commands](./codespace.md#project-commands); [HTTP/preview](./codespace.md#http-smoke-tests-and-production-preview); [E2E](./codespace.md#browser-end-to-end-tests) |
| Cross-cutting engineering rules | [../AGENTS.md](../AGENTS.md) |

`task-history.md` is an archive, not routine onboarding material. `todos.md` is
backlog context rather than a required read for unrelated code changes.
